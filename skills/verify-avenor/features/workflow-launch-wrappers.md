# Workflow launch wrappers — `avenor stable` + `avenor workflow`

## What it proves

A template's `launch_wrappers` names a trusted argv template (a wrapper
executable plus fixed and instance-param arguments) the supervisor resolves
when it dispatches a node. The wrapper is invoked with the node's
`working_directory` (from an instance param) as its first argument, then
`exec`s the backend; its dropped marker is what the node's `files`
completion contract checks.

## Prerequisites (cross-ref `../SKILL.md` and `stable-control.md`)

- Build the binary: `mise run go-build` (→ `./avenor`).
- Doctor: `command -v pi` — the backend must exist with a working default
  model. Export `MODEL` to an installed Pi model before running the recipe
  (configured local/home models are valid).
- Fresh short scratch `SCRATCH=$(mktemp -d /tmp/avenor-verify.XXXXXX)`, with
  separate workflow/adapter roots isolated from the defaults:
  `--workflow-root "$SCRATCH/workflows"` and
  `--workflow-adapter-dir "$SCRATCH/adapters"` (create `adapters` as `0700`).
- Operator-supplied harmless wrapper: takes `run_dir` as its first argument,
  records its argv, writes a marker file, then `exec`s the backend.

## Fixture (runnable; the JSON is generated by the embedded python)

```bash
set -eu; cd "$(git rev-parse --show-toplevel)"   # repo root, where ./avenor lives
SCRATCH=$(mktemp -d /tmp/avenor-verify.XXXXXX); WORK="$SCRATCH/work with spaces \$literal"
mkdir -p "$WORK"; mkdir -m 0700 "$SCRATCH/adapters"; SOCK="$SCRATCH/s.sock"
: "${MODEL:?Set MODEL to an installed Pi model}"
exec 3>"$SCRATCH/commands.log"; export BASH_XTRACEFD=3; set -x
WRAPPER="$SCRATCH/record-and-exec"
printf '#!/bin/sh\nset -eu\nprintf "%%s\\0" "$@" > "$1/wrapper.argv"\nprintf "wrapped\\n" > "$1/wrapped.txt"\nshift\nexec "$@"\n' > "$WRAPPER"
chmod 0700 "$WRAPPER"
python3 - "$SCRATCH" "$WORK" "$WRAPPER" "$MODEL" <<'PY'
import json, sys
s, work, wrapper, model = sys.argv[1:5]
open(s + "/roster.json", "w").write(json.dumps({"worker": {"backend": "pi", "agent": "mule", "model": model, "thinking": "low"}}))
t = {"schema_version": 1, "template_id": "verify-launch-wrapper", "template_version": "1",
     "entry_nodes": ["start"], "terminal_outcomes": ["done"],
     "params": [{"id": "run_dir", "type": "string", "required": True}],
     "working_directory": {"from_instance_param": "run_dir"},
     "launch_wrappers": [{"id": "record", "argv": [
         {"type": "literal", "value": wrapper}, {"type": "instance_param", "from_instance_param": "run_dir"}]}],
     "default_lease_policy": {"ttl_seconds": 120, "heartbeat_interval_seconds": 10},
     "nodes": [{"id": "start", "launch_wrapper": "record", "action": {"type": "run", "prompt": "Reply with the single word OK and nothing else."},
         "assignment": {"role": "worker", "roster_file": s + "/roster.json", "roster_entry": "worker"}, "dispatch": {"mode": "auto", "controller_id": "verify-wrapper"},
         "completion": {"kind": "files", "artifacts": [{"path": "wrapped.txt", "non_empty": True}]}, "outcomes": [{"name": "done", "terminal": True}]}]}
open(s + "/template.json", "w").write(json.dumps(t, indent=2) + "\n"); open(s + "/controller.json", "w").write(json.dumps({"controller_id": "verify-wrapper", "max_inflight": 1}) + "\n"); open(s + "/instance.json", "w").write(json.dumps({"params": {"run_dir": work}}) + "\n")
PY
```

## Drive (full real commands; only the polling loop is elided control flow)

```bash
./avenor stable --control-socket "$SOCK" \
  --workflow-root "$SCRATCH/workflows" --workflow-adapter-dir "$SCRATCH/adapters" \
  --max-runtimes 2 --idle-timeout 8m --shutdown-timeout 10s &> "$SCRATCH/stable.log" &
STABLE_PID=$!   # record this — cleanup kills THIS pid only (see stable-control.md)
for _i in $(seq 1 50); do   # ~10 s deadline
  kill -0 "$STABLE_PID" 2>/dev/null || { echo "FAIL: supervisor exited"; exit 1; }
  ./avenor control --socket "$SOCK" list >/dev/null 2>&1 && break
  sleep 0.2
done
./avenor control --socket "$SOCK" list >/dev/null 2>&1 || { echo "FAIL: socket not ready"; exit 1; }

./avenor workflow create --socket "$SOCK" --request-file "$SCRATCH/template.json"
./avenor workflow controller create --socket "$SOCK" --request-file "$SCRATCH/controller.json"  # desired_state=disabled
WF=$(./avenor workflow instantiate --socket "$SOCK" --template-id verify-launch-wrapper --template-version 1 --request-file "$SCRATCH/instance.json" | python3 -c 'import json,sys;print(json.load(sys.stdin)["workflow_id"])')

./avenor workflow ready --socket "$SOCK" verify-wrapper          # advisory check
./avenor workflow controller enable --socket "$SOCK" verify-wrapper
for _i in $(seq 1 120); do   # ~60 s deadline
  kill -0 "$STABLE_PID" 2>/dev/null || { echo "FAIL: supervisor exited"; exit 1; }
  S=$(./avenor workflow status --socket "$SOCK" "$WF" | python3 -c 'import json,sys;print(json.load(sys.stdin)["status"])')
  case "$S" in completed) break;; blocked|failed|canceled) echo "FAIL: $S"; exit 1;; esac
  sleep 0.5
done
S=$(./avenor workflow status --socket "$SOCK" "$WF" | python3 -c 'import json,sys;print(json.load(sys.stdin)["status"])')
[ "$S" = "completed" ] || { echo "FAIL: timed out, status=$S"; exit 1; }
```

## Evidence (capture before cleanup; copy out of the scratch dir first)

```bash
EV=/tmp/avenor-verify-evidence/$(date +%Y%m%d-%H%M%S); mkdir -p "$EV"
./avenor workflow status --socket "$SOCK" "$WF" > "$EV/workflow-status.json"
./avenor workflow inspect --socket "$SOCK" "$WF" > "$EV/workflow-inspect.json"
./avenor workflow events --socket "$SOCK" "$WF" --after-seq 0 --limit 100 > "$EV/workflow-events.json"
./avenor workflow controller status --socket "$SOCK" verify-wrapper > "$EV/controller-status.json"
RT=$(python3 -c 'import json;a=json.load(open("'"$EV"'/workflow-inspect.json"))["attempts"];a=list(a.values()) if isinstance(a,dict) else a;print(a[0]["identity"]["runtime_id"])')   # runtime_id is nested under identity
./avenor control --socket "$SOCK" status "$RT" > "$EV/runtime-status.json"
cp "$(python3 -c 'import json;print(json.load(open("'"$EV"'/runtime-status.json"))["sentinel_file"])')" "$EV/done.env"
cp "$(python3 -c 'import json;print(json.load(open("'"$EV"'/runtime-status.json"))["on_event"])')" "$EV/events.ndjson"
cp "$WORK/wrapped.txt" "$EV/wrapped.txt"
python3 -c 'import json,sys;print(json.dumps([x.decode() for x in open(sys.argv[1],"rb").read().split(b"\0") if x]))' "$WORK/wrapper.argv" > "$EV/wrapper-argv.json"
cp "$SCRATCH"/{template,controller,instance,roster}.json "$EV/"   # full fixture files
cp "$SCRATCH/commands.log" "$EV/"   # stable command argv + full transcript
./avenor control --socket "$SOCK" shutdown graceful
kill "$STABLE_PID" 2>/dev/null || true
wait "$STABLE_PID" 2>/dev/null || true
rm -rf "$SCRATCH"   # never delete "$EV"
```

## Observable end state (the proof)

- `workflow-status.json`: `"status": "completed"`, `"terminal_outcome": "done"`.
- `workflow-inspect.json`: **exactly one** attempt, `"status": "succeeded"`,
  with `identity.runtime_id` set (nested, not top-level).
- `runtime-status.json`: `"exit_code": 0`, `"final_output"` containing `OK`,
  `"pending_permission": false`, `"status": "ended"`.
- `done.env`: `DONE` and `STOP_REASON=end_turn`; `events.ndjson` has
  `session.start` and a terminal `session.end`.
- `wrapper-argv.json`: the **first** element is the `run_dir` with its spaces
  and `$` **unchanged** (no shell expansion or trimming), followed by the real
  backend argv (`pi --mode rpc ...`); and `wrapped.txt` (the wrapper-created
  marker the `files` completion checked) is present and non-empty, with the
  staged artifact recorded in the inspect `evidence` list.

## Gotchas

- The wrapper is operator-supplied and must be harmless: it records argv,
  writes the marker, then `exec`s the backend — it never alters the backend
  argv or the `run_dir`.
- `action.timeout`, if present, is a non-negative integer in **seconds**
  (`cmd/avenor/workflow.go` / `internal/workflow/model.go`); it is omitted
  here, so the attempt runs unbounded.
- The instantiate `--request-file` only reads `params` (and optional
  `metadata`); `template_id`/`template_version` come from the flags.
- Cleanup is `control shutdown graceful` + the recorded `STABLE_PID` only —
  never `pkill`; copy evidence out before `rm -rf` of the scratch dir.
